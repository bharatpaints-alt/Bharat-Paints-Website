💡 KEY PRINCIPLES

1. SUBTLETY
   - Animations are smooth, not distracting
   - Colors are sophisticated, not garish
   - Effects enhance, not overpower

2. CONSISTENCY
   - Same animation timing throughout (200-600ms)
   - Color palette strictly applied
   - Spacing follows 8px grid

3. ACCESSIBILITY
   - Color contrast ratios WCAG AA
   - Keyboard navigation supported
   - prefers-reduced-motion respected

4. PERFORMANCE
   - 60fps animations (transform + opacity only)
   - Lazy load non-critical sections
   - Optimized images (Next/Image)

5. MOBILE-FIRST
   - Touch targets minimum 48x48px
   - Responsive typography scaling
   - Thumb-friendly navigation
